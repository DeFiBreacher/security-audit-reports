### 📋 Description

The `withdraw` instruction in the vault program does not verify that the `authority` account has signed the transaction. This means any unsigned account can be passed as `authority`, allowing an attacker to withdraw funds from any vault they do not own.

This is a critical access control failure — the program trusts the account label without cryptographic verification.

---

### 💥 Impact

An attacker can drain the entire balance of any vault in the protocol without needing the owner's private key.

- **Worst case**: Full theft of all depositor funds across every vault
- **Likelihood**: High — exploit requires no special setup or preconditions
- **Affected users/assets**: All depositors; entire protocol TVL at risk

---

### 🔬 Proof of Concept

> ⚠️ **REQUIRED** — independently verifiable

The attacker creates a transaction calling `withdraw`, passing a victim's vault address and their own wallet as `authority` — without signing as the vault owner. The program accepts it.

**Expected behavior:**
Transaction fails with `MissingRequiredSignature` if `authority` has not signed.

**Actual behavior:**
Transaction succeeds and funds are transferred to the attacker's wallet.

```typescript
it("drains vault without owner signature", async () => {
  const attacker = Keypair.generate();

  await program.methods
    .withdraw(new BN(1_000_000))
    .accounts({
      vault: victimVault,
      authority: victimAuthority, // attacker passes victim's pubkey
      destination: attacker.publicKey,
    })
    .signers([attacker]) // only attacker signs — NOT the vault owner
    .rpc();

  const vaultBalance = await getBalance(victimVault);
  assert.equal(vaultBalance, 0); // vault fully drained
});
```

---

### ✅ Recommended Fix

Add a signer constraint on the `authority` account in the account validation struct.

**Before:**
```rust
#[derive(Accounts)]
pub struct Withdraw<'info> {
    #[account(mut, has_one = authority)]
    pub vault: Account<'info, Vault>,
    pub authority: SystemAccount<'info>,  // ❌ no signer check
    #[account(mut)]
    pub destination: SystemAccount<'info>,
}
```

**After:**
```rust
#[derive(Accounts)]
pub struct Withdraw<'info> {
    #[account(mut, has_one = authority)]
    pub vault: Account<'info, Vault>,
    pub authority: Signer<'info>,  // ✅ enforces signature verification
    #[account(mut)]
    pub destination: SystemAccount<'info>,
}
```
